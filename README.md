# MScRes_Micro_mineral_analysis_simplified_workflow

This repository contains scripts, methodologies, and supporting materials used to analyse micro-scale mineralogical data from sulphide-bearing samples within the Rum Layered Intrusion, Scotland. The workflow was developed to streamline data preparation, machine learning analysis, mineral classification, and interpretation of complex elemental phases.

The project explores approaches for:
- SEM-EDS hyperspectral data processing
- Data quality optimisation and exposure calibration
- Poisson noise scaling
- Factor Analysis (FA)
- HDBSCAN clustering
- Mineral phase identification
  
The workflow was simplified to improve reproducibility and accessibility for researchers working with large microanalytical datasets.

## Workflow Summary
1. Data Acquisition
- SEM imaging
- SEM-EDS elemental mapping
- Export of spectral and elemental datasets
2. Data Preparation
- Import raw datasets
- Data normalisation
- Poisson noise scaling
3. Dimensionality Reduction
- Factor Analysis (FA)
4. Unsupervised Classification
- HDBSCAN clustering
5. Interpretation
- Mineralogical classification
- Sulphide alteration investigations
- Geological interpretation
6. Visualisation
- Cluster maps
- Comparative mineralogical summaries

- Ore deposit studies
- Petrology research
- Mineral chemistry investigations

- SEM-EDS hyperspectral datasets
